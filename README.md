# 🏠 Daily Life Problem Solver – Home Maintenance Reminder

## 📌 Project Overview

**Home Maintenance Reminder** is a simple application designed to help people manage their daily household maintenance tasks. Many people forget important activities such as water filter servicing, electricity bill payments, appliance maintenance, and other household tasks.

This application helps users organize their tasks, set reminders, and maintain a history of completed activities.

## 🎯 Problem Statement

People often forget important household maintenance activities and bill payment dates because they have busy schedules. This can lead to delayed payments, appliance problems, and unnecessary expenses.

The Home Maintenance Reminder application provides a simple and convenient solution to organize daily tasks and remind users about upcoming maintenance activities.

## 💡 Proposed Solution

The application allows users to add household tasks, set due dates, view upcoming activities, and mark tasks as completed.

It helps users manage their daily responsibilities more efficiently and reduces the chances of missing important tasks.

## ✨ Features

- 🔐 User Login and Registration
- 📊 Dashboard to View Tasks
- ➕ Add New Maintenance Tasks
- ✏️ Edit Existing Tasks
- 🗑️ Delete Tasks
- 📅 Set Task Due Dates
- 🔔 Task Reminder Management
- ✅ Mark Tasks as Completed
- 📜 View Completed Task History
- ⚙️ Settings and User Profile
- 👁️ Show/Hide Password Option
- 🔑 Forgot Password Option

## 🚀 How to Run the Project

### Step 1: Install Python

Download and install Python from the official website:

https://www.python.org/

### Step 2: Open the Project

Open the project folder in Visual Studio Code.

### Step 3: Check Tkinter

Tkinter is generally included with standard Python installations.

Run this command in the VS Code terminal:

```bash
python -m tkinter
```

If a small Tkinter window appears, it is working correctly.

### Step 4: Run the Application

Run the following command in the VS Code terminal:

```bash
python app.py
```

**Note:** Make sure your main Python file is named `app.py`. If you use another filename, replace `app.py` with that filename.
